## ONDO Mistral Control Relay

Öffentlicher, minimaler Transportkanal für verschlüsselte Browser-Steuerbefehle des Projekts **Training Mistral**.

## Sicherheitsgrenzen

* Keine Klartext-Prompts.
* Keine Projektdaten aus `ondo-ai-lab`.
* Keine API-Schlüssel, Tokens oder sonstigen Geheimnisse.
* `ondo-ai-lab` bleibt die private, verbindliche Projektquelle.
* Dieses Repository dient ausschließlich als Transportinfrastruktur.

Öffentlich gespeicherte Relay-Nutzdaten müssen verschlüsselt sein.
